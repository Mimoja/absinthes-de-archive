## Beschreibung

Mit diesem Set erhalten Sie eine 20cl Flasche vom Absinth Jade Esprit Edouard und eine SLIPSTREAM® Absinth Pfeife.

Der** Jade Esprit Edouard** ist ein Replikat des historischen Edouard Pernod Absinth, einer der beliebtesten Absinthe während der Belle Epoque. Die **SLIPSTREAM® Absinth Pfeife** ist aus nahezu bruchsicherem Borosilikat Glas gefertigt. Sie ist besonders praktisch und ermöglicht Ihnen den Absinth auf eine neue Art und Weise zu servieren.
