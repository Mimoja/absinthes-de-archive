## Beschreibung

Mit diesem Set können Sie den **Absinthe Libertine 55 Originale** genießen. Zusätzlich erhalten Sie einen **Absinthe Löffel**, um so traditionelle Ritual durchzuführen.

Das Set **eignet sich sehr gut als Geschenk** für Ihre Freunde!

Der Absinthe Libertine 55 Originale hat eine dezente Anis-Note und einen sanften Geschmack. Die Herstellung erfolgt nach einem Originalrezept aus dem Jahr 1894 in der Paul Devoille Destillerie.

Typisch für die Libertine Absinthe ist die Herstellung durch eine Zusammenstellung von Destillaten: die Pflanzen werden einzeln destilliert, dann maziert und abschließend mit verschiedenen Destillaten vermischt. Dadurch entsteht der **perfekte Libertine 55**!
